# Les dix-sept achats intégrés, à recopier

Un bloc par article, dans l'ordre où App Store Connect demande les champs.
Coche au fur et à mesure : un article créé ne se supprime pas, et son
identifiant ne se réutilise pas — c'est le seul champ irréversible du lot.

Pour les dix-sept : **Type = Non consommable**, **Langue = Anglais
(États-Unis)**, **Partage familial = activé**, prix à ton choix (2,99 $ dans le
fichier d'essai).

Le nom de référence et l'identifiant se saisissent dans le dialogue de
création. Le nom d'affichage et la description viennent après, dans
« Ajouter la langue dans l'App Store ». La capture va dans « Informations pour
la vérification ».
